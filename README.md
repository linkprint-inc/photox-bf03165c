# photoX

Create a completely NEW homepage concept for PhotoX.

IMPORTANT:

Do NOT modify or iterate on the previous homepage.

Treat this as an independent design direction.

This is CONCEPT B.

PhotoX is being repositioned as a modern, product-first e-commerce store

for premium physical wall art.

The primary products are:

1. Metal Prints

2. Frameless Canvas Prints

3. Ready-to-buy artwork

4. Custom prints made from the customer's own image

PhotoX is NOT an AI-first product.

Only retain three image preparation utilities:

- Restore Old Photo

- Enhance Resolution

- Add Text

Do not market these as AI features.

They are secondary tools that help customers prepare images for printing.

The commercial goal is simple:

MAKE PEOPLE WANT THE PHYSICAL PRODUCT.

==================================================

CORE CREATIVE DIRECTION

==================================================

Create a quiet, highly visual commerce experience.

The interface should feel almost invisible when untouched,

but become richer when the user interacts with it.

The visual identity should come from:

ARTWORK

LIGHT

PHYSICAL MATERIAL

SCALE

SPACE

MOTION

—not decorative UI.

The desired feeling:

QUIET AT REST.

RICH ON INTERACTION.

CLEARLY E-COMMERCE.

Take general inspiration from refined contemporary furniture,

photography and art-commerce websites where:

- navigation integrates into photography

- large imagery carries the design

- information is progressively revealed

- hover states expose product details

- editorial layouts coexist with commerce

- whitespace is generous

- interfaces feel calm rather than empty

Do NOT copy any specific reference website.

Do NOT create a generic Shopify homepage.

Do NOT create a standard sequence of:

Hero

→ cards

→ product grid

→ feature icons

→ testimonials

→ footer

Create more rhythm and visual tension.

==================================================

VISUAL SYSTEM

==================================================

Use a predominantly white / soft warm-white canvas.

Artwork provides most of the color.

Occasionally use deep charcoal only when it creates a meaningful

contrast moment.

Do not alternate section background colors unnecessarily.

Typography should combine:

a restrained editorial serif for selected expressive headlines

with

a clean neutral sans-serif for:

navigation

prices

product information

sizes

controls

commerce UI

Do not overuse the serif.

Do not use giant 100px+ marketing headlines simply to fill space.

Typography should feel composed, not loud.

Avoid:

- excessive rounded corners

- pills everywhere

- gradients

- glassmorphism

- floating cards

- SaaS UI

- colorful badges

- giant icon rows

- fake metallic interface effects

- excessive shadows

Use square / near-square geometry,

thin rules,

precise spacing,

and large photography.

==================================================

GLOBAL INTERACTION LANGUAGE

==================================================

Interaction is part of the visual identity.

Use one consistent principle:

INFORMATION APPEARS AS THE USER EXPLORES.

At rest:

the page remains visually quiet.

On hover / focus / tap:

reveal useful secondary information.

Reveal:

material

size

price

product description

surface detail

context

CTA

Do not reveal meaningless decorative effects.

Essential commerce information such as product name and starting price

must NOT depend entirely on hover.

Use restrained transitions:

approximately 350–650ms.

No bouncing.

No dramatic zooming.

No excessive parallax.

No spinning.

No animation for animation's sake.

==================================================

NAVIGATION — PART OF THE PAGE

==================================================

Create a minimal adaptive navigation.

Desktop:

Left:

PHOTX

Center:

SHOP

METAL

CANVAS

CUSTOM

PHOTO TOOLS

Right:

SEARCH

ACCOUNT

BAG (0)

The navigation initially sits transparently over the hero photography.

No visible navbar container.

Its text color should adapt between light and dark depending on the

background underneath.

When scrolling DOWN:

the navigation smoothly disappears upward.

When scrolling UP:

it returns.

When it returns over white content:

use a very subtle warm-white surface with dark text.

No strong blur.

No glass effect.

No heavy shadow.

Navigation should feel embedded in the site.

==================================================

01 — HERO AS A PRODUCT, NOT A BANNER

==================================================

Do NOT design a conventional hero with:

headline on left

image on right

two large CTA buttons

Instead create a nearly full-viewport photographic product scene.

Show a large Metal Print installed in a beautiful contemporary interior.

The room should feel real, architectural and lived-in,

not like generic staged stock photography.

The Metal Print is the visual protagonist.

Natural daylight enters from one side.

Part of the light catches the glossy Metal surface,

creating a controlled realistic reflection.

The user should understand that the artwork is a PHYSICAL METAL OBJECT

before reading the copy.

Keep text integrated into the photography.

Small category label:

METAL PRINTS

Primary line:

ART THAT CHANGES WITH THE LIGHT.

Secondary commerce information:

Pacific Light No. 03

24 × 36"

$189

Primary CTA:

SHOP THE PRINT

Secondary text link:

CREATE YOUR OWN →

Do not place the copy inside a large box.

Use the negative space of the photography.

On hover over the artwork itself:

subtly change the reflected highlight

and reveal a small contextual label:

GLOSS METAL

24 × 36"

VIEW →

The effect must remain physically believable.

==================================================

04 — METAL INTERRUPTION

==================================================

Interrupt the product wall with a dramatic material moment.

Do not use a normal centered section.

Use one oversized close-up Metal Print image occupying roughly

60–70% of the width.

Crop it close enough that the user sees:

image

surface

reflection

edge

Use the remaining whitespace for:

WHY METAL?

Light becomes part of the image.

Glossy surface

Crisp detail

Deep color

Rigid profile

FROM $XX

EXPLORE METAL →

As the user scrolls into this section,

allow a very subtle change in reflected light across the print.

No shimmer.

No glowing.

No CGI effect.

Think real daylight moving across aluminum.

==================================================

05 — SIZE AS VISUAL COMMERCE

==================================================

Do NOT create a conventional "Shop by Size" card row.

Create a large shared wall scene.

One fixed interior reference:

for example a console, bench or sofa.

Above it,

show the same wall-art position.

Provide a typographic size selector:

12 × 18

16 × 24

20 × 30

24 × 36

30 × 40

When a size is hovered or selected:

the artwork on the SAME wall changes to the correct physical scale.

The environment remains fixed.

Price updates simultaneously.

Example:

24 × 36"

$189

The difference between the smallest and largest size must be dramatic

and believable.

Include:

SELECT SIZE

SHOP THIS SIZE →

This should feel like shopping,

not like a technical size calculator.

On mobile:

use tap selection.

Focus on statement-scale art.

Gallery-wrapped edge

FROM $XX

EDGE +

DETAIL +

CARE +

Only one is open at a time.

Keep this section minimal despite its interactivity.

09 — CUSTOM: IMAGE BECOMES OBJECT

Second state:

Allow hover / drag / tap to reveal the transformation.

The final print should show:

edge

depth

surface

reflection

YOUR IMAGE.

MADE FOR THE WALL.

==================================================

10 — PHOTO TOOLS AS A QUIET UTILITY

==================================================

Do not create three large feature cards.

Create a compact utility section.

Small heading:

BEFORE YOU PRINT

Intro:

Need a little help with your image?

Use three clean expandable rows:

RESTORE OLD PHOTO          +

ENHANCE RESOLUTION         +

ADD TEXT                   +

slightly change text tone.

On click:

expand one row.

RESTORE OLD PHOTO

Repair fading, scratches and age-related damage before printing.

ENHANCE RESOLUTION

Prepare smaller images for larger print sizes.

ADD TEXT

Add a date, name, caption or personal message.

Only one row open at a time.

Optionally show one small before / after image beside the active item.

Do not mention AI.

This section should feel useful but secondary.

MADE FOR REAL WALLS.

==================================================

ART DIRECTION

==================================================

Do not fill the site with beige landscape photography.

Keep the UI neutral,

but make the artwork varied.

Curate:

architecture

landscape

coastal

abstract

black and white

urban photography

bold blue

occasional red / orange

portrait / figurative

graphic contemporary artwork

The artwork creates color.

The interface creates calm.

Interior photography should feel:

architectural

natural

contemporary

slightly editorial

realistic

lived-in

Avoid:

generic luxury penthouses

fake Scandinavian stock rooms

excessive beige

over-styled hotel interiors

==================================================

PHYSICAL PRODUCT RULE

==================================================

Metal Prints and Canvas must NEVER look like the same digital image

with different labels.

METAL must visibly show:

GLOSS

REFLECTION

RIGIDITY

THIN EDGE

CRISP DETAIL

CANVAS must visibly show:

MATTE SURFACE

WOVEN TEXTURE

WRAPPED EDGE

SOFTER LIGHT RESPONSE

Material differences should be understood visually.

==================================================

PRICE RULE

==================================================

PhotoX is a STORE.

Price must remain visible throughout the experience.

Show prices in:

Hero

Commerce Index

Product Wall

Metal feature

Size selector

Large Format

Material Explorer

Room products

Custom Prints

Do not hide all pricing behind hover.

Hover reveals secondary information.

Price is primary commerce information.

==================================================

MOBILE

==================================================

Reinterpret the experience for touch.

Do not merely shrink desktop.

Navigation:

transparent over hero,

hide when scrolling down,

return when scrolling up.

Product wall:

2 columns where appropriate.

Large editorial products:

1 column.

Material explorer:

tap interaction.

Size selector:

horizontal size controls with one shared preview.

Room section:

tap to reveal product information.

Custom transformation:

tap or drag.

Photo Tools:

accordion.

Do not require hover for any essential information.

Avoid excessive vertical gaps.

==================================================

ACCESSIBILITY / USABILITY

==================================================

All interactions must have keyboard/focus states.

Maintain readable contrast,

especially for adaptive navigation and text over photography.

Respect prefers-reduced-motion.

Do not let animation delay purchasing actions.

Do not hide:

prices

product names

Add to Cart / purchase paths

behind hover-only states.

==================================================

FINAL EXPERIENCE

==================================================

Do not make PhotoX look "designed" through more decoration.

Make it feel designed through:

composition

spacing

material photography

adaptive typography

interaction

scale

light

The homepage should be visually calm when viewed as a screenshot,

but noticeably richer when actually used.

A visitor should leave with four immediate impressions:

1. PhotoX sells beautiful wall art.

2. Metal Prints are the hero product.

3. The physical finish and size matter.

4. I can either buy existing art or print my own.

Above all:

THIS IS AN E-COMMERCE STORE.

Every beautiful interaction should ultimately help the visitor

understand, choose, or buy a physical product.
